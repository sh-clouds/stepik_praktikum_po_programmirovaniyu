Уравнение

Решить в целых числах уравнение ax + b = 0.

Входные данные
Вводятся 2 целых числа: a и b.

Выходные данные
Необходимо вывести все решения, если их число конечно, “NO” (без кавычек), если решений нет, и “INF” (без кавычек), если решений бесконечно много.

Sample Input:
6
-2

Sample Output:
NO

# rust
use std::io::{self, Read};

fn main() {
    // Read the entire standard input
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).unwrap();

    // Parse the first two whitespace‑separated values as signed 64‑bit integers
    let mut numbers = input.split_whitespace().map(|s| s.parse::<i64>().unwrap());
    let a = numbers.next().unwrap_or(0);
    let b = numbers.next().unwrap_or(0);

    // Compute the result following the same logic as the Ruby script
    let result = if a == 0 && b != 0 {
        // a is zero but b is non‑zero → impossible division
        "NO".to_string()
    } else if a == 0 {
        // a is zero and b is also zero → infinitely many solutions
        "INF".to_string()
    } else if b != 0 && (-b) % a != 0 {
        // Division would not be exact
        "NO".to_string()
    } else {
        // Exact integer division (the earlier checks guarantee divisibility)
        ((-b) / a).to_string()
    };

    println!("{}", result);
}
