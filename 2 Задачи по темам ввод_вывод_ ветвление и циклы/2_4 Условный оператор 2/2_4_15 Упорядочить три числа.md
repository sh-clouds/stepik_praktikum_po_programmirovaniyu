Упорядочить три числа

Дано три числа, записанных в отдельных строках. Упорядочите их в порядке неубывания. Программа должна считывать три числа a, b, c, затем программа должна менять их значения так, чтобы стали выполнены условия a <= b <= c, затем программа выводит тройку a, b, c.

Входные данные
Вводятся три числа, каждое записано в отдельной строке.

Выходные данные
Выведите ответ на задачу.

Sample Input:
1
2
1

Sample Output:
1 1 2

Напишите программу. Тестируется через stdin → stdout

# rust
use std::io::{self, Read};

fn main() {
    // Read the whole input (three numbers, each possibly on its own line)
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).unwrap();
    let mut values = input
        .split_whitespace()
        .map(|s| s.parse::<f64>().unwrap())
        .take(3)
        .collect::<Vec<f64>>();

    // Ensure we have exactly three numbers; missing ones default to 0.0
    while values.len() < 3 {
        values.push(0.0);
    }

    // Unpack into distinct variables for clarity
    let mut a = values[0];
    let mut b = values[1];
    let mut c = values[2];

    // Sort the three numbers in ascending order (bubble‑sort style)
    if a > b {
        std::mem::swap(&mut a, &mut b);
    }
    if b > c {
        std::mem::swap(&mut b, &mut c);
    }
    if a > b {
        std::mem::swap(&mut a, &mut b);
    }

    // Helper to print an integer without a trailing “.0” when possible
    fn format_number(x: f64) -> String {
        if x.fract().abs() < f64::EPSILON {
            // Safe to cast because the fractional part is zero
            format!("{}", x as i64)
        } else {
            format!("{}", x)
        }
    }

    // Output the three numbers separated by a single space
    println!(
        "{} {} {}",
        format_number(a),
        format_number(b),
        format_number(c)
    );
}
