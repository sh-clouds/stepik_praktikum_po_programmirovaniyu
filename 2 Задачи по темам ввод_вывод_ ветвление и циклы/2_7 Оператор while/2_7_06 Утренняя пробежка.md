Утренняя пробежка

В первый день спортсмен пробежал x километров, а затем он каждый день увеличивал пробег на 10% от предыдущего значения. По данному числу y определите номер дня, на который пробег спортсмена составит не менее y километров.

Входные данные
Программа получает на вход действительные числа x и y

Выходные данные
Программа должна вывести одно натуральное число.

Sample Input:
10
20

Sample Output:
9

Напишите программу. Тестируется через stdin → stdout

# rust
use std::io::{self, Read};

fn main() {
    // Read the entire stdin into a string
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).expect("Failed to read input");

    // Split whitespace and parse the first two numbers as f64
    let mut values = input.split_whitespace()
                          .map(|s| s.parse::<f64>()
                                   .expect("Please provide valid numbers"));

    let mut current_amount = values.next().expect("Missing first number");
    let target_amount = values.next().expect("Missing second number");
    let mut day_counter: i32 = 1;

    // Increase `current_amount` by 10 % each day until it reaches or exceeds `target_amount`
    while current_amount < target_amount {
        current_amount *= 1.1;
        day_counter += 1;
    }

    // Output the number of days required
    println!("{}", day_counter);
}
