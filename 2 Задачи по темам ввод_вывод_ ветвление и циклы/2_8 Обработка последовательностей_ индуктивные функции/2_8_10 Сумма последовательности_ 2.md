Сумма последовательности - 2

Найдите сумму последовательности натуральных чисел, если признаком окончания конца последовательности является два подряд идущих числа 0.

Числа, следующие после двух подряд идущих нулей считывать не нужно.

Входные данные
Вводится последовательность целых чисел, оканчивающаяся числом 0 (само число 0 в последовательность не входит).

Выходные данные
Выведите ответ на задачу.

Sample Input:
1
0
7
0
9
0
0

Sample Output:
17

Напишите программу. Тестируется через stdin → stdout

# rust
use std::io::{self, BufRead};

fn main() {
    // Accumulator for the sum of the entered numbers
    let mut total: i64 = 0;
    // Flag that indicates the previous input was zero
    let mut zero_flag = false;

    // Read from standard input line by line
    let stdin = io::stdin();
    for line in stdin.lock().lines() {
        // If reading fails, exit the loop
        let line = match line {
            Ok(l) => l,
            Err(_) => break,
        };

        // Trim whitespace and attempt to parse an integer
        let cur: i64 = match line.trim().parse() {
            Ok(num) => num,
            Err(_) => continue, // ignore non‑numeric lines
        };

        if cur == 0 && zero_flag {
            // Two consecutive zeros – stop processing
            break;
        } else if cur == 0 {
            // First zero encountered; set the flag and continue
            zero_flag = true;
        } else {
            // Non‑zero number: reset flag and add to total
            zero_flag = false;
            total += cur;
        }
    }

    // Output the accumulated sum
    println!("{}", total);
}
