Количество элементов, которые больше предыдущего

Последовательность состоит из натуральных чисел и завершается числом 0. Определите, сколько элементов этой последовательности больше предыдущего элемента.

Числа, следующие за числом 0, считывать не нужно.

Входные данные
Вводится последовательность целых чисел, оканчивающаяся числом 0 (само число 0 в последовательность не входит).

Выходные данные
Выведите ответ на задачу.

Sample Input:
1
7
9
0

Sample Output:
2

Напишите программу. Тестируется через stdin → stdout

# rust
use std::io::{self, BufRead};

fn main() {
    // Counter for the number of times the current value exceeds the previous one
    let mut qty: i32 = 0;
    // Holds the previous integer value, initially none
    let mut prev: Option<i32> = None;

    // Read lines from standard input until the sentinel "0" is encountered
    let stdin = io::stdin();
    for line_result in stdin.lock().lines() {
        let line = match line_result {
            Ok(l) => l,
            Err(_) => break, // Stop on read error
        };
        let trimmed = line.trim();

        // Sentinel check – stop processing when "0" is entered
        if trimmed == "0" {
            break;
        }

        // Parse the input line to an integer
        let cur: i32 = match trimmed.parse() {
            Ok(num) => num,
            Err(_) => continue, // Skip invalid numbers
        };

        // If this is the first number, just store it as previous
        if prev.is_none() {
            prev = Some(cur);
            continue;
        }

        // At this point `prev` is guaranteed to be `Some`
        if let Some(prev_val) = prev {
            if cur > prev_val {
                qty += 1;
            }
        }

        // Update previous value for the next iteration
        prev = Some(cur);
    }

    // Output the final count
    println!("{}", qty);
}
