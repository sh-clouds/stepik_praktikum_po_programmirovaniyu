Последовательность состоит из натуральных чисел и завершается числом 0. Определите значение второго по величине элемента в этой последовательности, то есть элемента, который будет наибольшим, если из последовательности удалить наибольший элемент.

Числа, следующие за числом 0, считывать не нужно.

Входные данные
Вводится последовательность целых чисел, оканчивающаяся числом 0 (само число 0 в последовательность не входит).

Выходные данные
Выведите ответ на задачу.

Sample Input:
1
7
9
0

Sample Output:
7

Напишите программу. Тестируется через stdin → stdout

# rust
use std::io::{self, BufRead};

fn main() {
    // Variables to keep track of the largest and second‑largest values.
    let mut prev_mx: i64 = 0;
    let mut cur_mx: i64 = 0;

    // Read lines from standard input until a line containing only "0" is encountered.
    let stdin = io::stdin();
    for line_result in stdin.lock().lines() {
        let line = match line_result {
            Ok(l) => l,
            Err(_) => continue, // Skip unreadable lines.
        };
        let trimmed = line.trim();

        // Sentinel value – stop processing.
        if trimmed == "0" {
            break;
        }

        // Parse the input number; ignore the line if it cannot be parsed.
        let el: i64 = match trimmed.parse() {
            Ok(v) => v,
            Err(_) => continue,
        };

        if cur_mx == 0 {
            // First number read becomes the current maximum.
            cur_mx = el;
            continue;
        }

        if prev_mx < el && el < cur_mx {
            // Found a value between the previous and current maximum.
            prev_mx = el;
        } else if el > cur_mx {
            // Found a new maximum; shift the old maximum down.
            prev_mx = cur_mx;
            cur_mx = el;
        }
    }

    // Output the second‑largest distinct value (or 0 if not applicable).
    println!("{}", prev_mx);
}
