Разрезание на квадраты

Полоска бумаги имеет размеры A × B. Каждый раз от нее отрезается квадрат максимального размера до тех пор, пока не получится квадрат. Сколько квадратов получится?

Входные данные
Программе даны числа A и B (1 ≤ A, B ≤ 109).

Выходные данные
Требуется вывести количество квадратов.

Sample Input 1:
15 3

Sample Output 1:
5

Sample Input 2:
12 8

Sample Output 2:
3

Sample Input 3:
5 5

Sample Output 3:
1

Напишите программу. Тестируется через stdin → stdout

a, b = gets.split.map(&:to_i)

  k += 1
  if a > b
    a -= b
  else
    b -= a
  end
end

# rust
use std::io::{self, Read};

/// Recursively computes the value.
/// If `a == b` the function returns 1.
/// Otherwise it returns `a / b` plus, when `a % b != 0`, the recursive call
/// `f(b, a % b)`. The logic:
/// `int(a == b) or a//b + (a%b and f(b, a%b))`.
fn f(a: i64, b: i64) -> i64 {
    if a == b {
        1
    } else {
        let div = a / b;
        let rem = a % b;
        div + if rem != 0 { f(b, rem) } else { 0 }
    }
}

fn main() {
    // Read the whole input, split by whitespace and parse the two integers.
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).unwrap();
    let mut iter = input.split_whitespace().map(|s| s.parse::<i64>().unwrap());

    let a = iter.next().expect("first number missing");
    let b = iter.next().expect("second number missing");

    println!("{}", f(a, b));
}
