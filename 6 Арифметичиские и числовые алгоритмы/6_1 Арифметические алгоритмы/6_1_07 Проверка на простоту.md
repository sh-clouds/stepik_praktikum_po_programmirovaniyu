Проверка на простоту

Проверьте, является ли число простым.

Входные данные
Вводится одно натуральное число n не превышающее 2000000000 и не равное 1.

Выходные данные
Необходимо вывести  строку prime, если число простое, или composite, если число составное.

Sample Input:
5

Sample Output:
prime

Напишите программу. Тестируется через stdin → stdout

def is_prime?(n)
    if n < 4 then return n > 1 end
    k = 2
    while k*k <= n do
        if n%k == 0 then return false end 
        k += 1
    end        
    return true  
end

use std::io::{self, Read};

/// Checks whether `x` is prime.
/// The function counts how many integers `i` in the range `[1, sqrt(x))` divide `x` without a remainder.
/// If the count equals exactly 1, it prints `"prime"`; otherwise it prints `"composite"`.
fn is_prime(x: i64) {
    // Compute the integer part of sqrt(x)
    let limit = (x as f64).sqrt() as i64;

    // Count divisors in the half‑open interval [1, limit)
    let mut divisor_count = 0;
    for i in 1..limit {
        if x % i == 0 {
            divisor_count += 1;
        }
    }

    if divisor_count == 1 {
        println!("prime");
    } else {
        println!("composite");
    }
}

fn main() {
    // Read the whole input from stdin, trim whitespace and parse to i64
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).expect("Failed to read input");
    let n: i64 = input.trim().parse().expect("Input is not a valid integer");

    // Run the prime check
    is_prime(n);
}
