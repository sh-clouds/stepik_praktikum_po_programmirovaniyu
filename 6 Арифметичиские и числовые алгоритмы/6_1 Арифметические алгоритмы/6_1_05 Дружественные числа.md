Дружественные числа

Два различных натуральных числа n и m называются дружественными, если сумма делителей числа n (включая 1, но исключая само n) равна числу m и наоборот. Например, 220 и 284 – дружественные числа. По данному числу k выведите все пары дружественных чисел, каждое из которых не превосходит k.

Входные данные
Программа получает на вход одно натуральное число k, не превосходящее 105.

Выходные данные
Программа должна вывести  все пары дружественных чисел, каждое из которых не превосходит k. Пары необходимо выводить по одной в строке, разделяя пробелами. Каждая пара должна быть выведена только один раз (перестановка чисел новую пару не дает). В парах выводим сначала меньшее число, потом большее.

Если таких пар нет - выводить ничего не нужно.

Sample Input:
300
Sample Output:
220 284

def divisors_sum(num: int) -> int:
    'Sum of the proper divisors of num'
    sqrt_n = int(num ** .5)
    res = - num + sum(i + num // i for i in range(1, sqrt_n + 1) if not num % i)
    if sqrt_n * sqrt_n == num:
        res -= sqrt_n
    return res

use std::io::{self, Read};

/// Returns the sum of the proper divisors of `n`.
fn proper_divisor_sum(n: i64) -> i64 {
    let sqrt_n = (n as f64).sqrt() as i64;
    // start with -n because the loop adds both i and n/i, including n itself
    let mut sum = -n;
    for i in 1..=sqrt_n {
        if n % i == 0 {
            sum += i + n / i;
        }
    }
    // if n is a perfect square, we counted sqrt twice; remove one occurrence
    if sqrt_n * sqrt_n == n {
        sum -= sqrt_n;
    }
    sum
}

fn main() {
    // ---- read K ------------------------------------------------------------
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).expect("Failed to read stdin");
    let k: i64 = input.trim().parse().expect("Input must be an integer");

    // ---- find amicable pairs -----------------------------------------------
    let mut amicable_numbers: Vec<i64> = Vec::new();

    for n in 2..k {
        // skip numbers already recorded as part of a previous pair
        if amicable_numbers.contains(&n) {
            continue;
        }

        let m = proper_divisor_sum(n);
        // n < m guarantees each pair appears only once
        if n < m && m <= k && n == proper_divisor_sum(m) {
            amicable_numbers.push(n);
            amicable_numbers.push(m);
        }
    }

    // ---- output ------------------------------------------------------------
    let mut i = 0;
    while i + 1 < amicable_numbers.len() {
        println!("{} {}", amicable_numbers[i], amicable_numbers[i + 1]);
        i += 2;
    }
}
