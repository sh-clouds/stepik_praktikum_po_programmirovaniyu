Отрезок_0

На клетчатой бумаге Петя нарисовал отрезок из точки с координатами (a, b) в точку с координатами (c, d). Через сколько клеток проходит этот отрезок (считается, что отрезок проходит через клетку, если он проходит через ее внутренность, если же он проходит только через вершину или по границе клетки, считается, что он не проходит через клетку).

Входные данные
Вводятся целые числа a, b, c, d. Числа по модулю не превышают 10**9.

Выходные данные
Выведите одно число — количество клеток, через которые проходит отрезок.

Sample Input 1:
0 0 6 4

Sample Output 1:
8

Sample Input 2:
3 3 -3 3

Sample Output 2:
0

Напишите программу. Тестируется через stdin → stdout

# rust
use std::io::{self, Read};

/// Compute the greatest common divisor using the Euclidean algorithm.
fn gcd(mut a: i64, mut b: i64) -> i64 {
    while b != 0 {
        let r = a % b;
        a = b;
        b = r;
    }
    a.abs()
}

fn main() {
    // Read the entire input from stdin.
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).expect("Failed to read input");

    // Parse the four integers a, b, c, d.
    let mut iter = input.split_whitespace().map(|s| s.parse::<i64>().expect("Invalid integer"));
    let a = iter.next().expect("Missing value a");
    let b = iter.next().expect("Missing value b");
    let c = iter.next().expect("Missing value c");
    let d = iter.next().expect("Missing value d");

    // Absolute differences along each axis.
    let x_diff = (c - a).abs();
    let y_diff = (d - b).abs();

    // Result: Manhattan distance minus the GCD of the differences.
    let result = x_diff + y_diff - gcd(x_diff, y_diff);

    println!("{}", result);
}
