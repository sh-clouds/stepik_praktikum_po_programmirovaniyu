Установить значение бита в 1

Напишите программу, которая в заданном числе устанавливает определенный бит в 1 (биты при этом нумеруются с нуля, начиная от младших).

Входные данные
Дано целое число A и натуральное число i.

Выходные данные
Выведите число, которое получается из числа A установкой значения i-го бита = 1.

Sample Input:
5 1

Sample Output:
7

Напишите программу. Тестируется через stdin → stdout

# C++
#include <iostream>

# rust
use std::io::{self, Read};

fn main() {
    // Read the whole input from stdin
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).expect("Failed to read input");

    // Split the input by whitespace and parse the two integers
    let mut iter = input.split_whitespace();
    let base: i64 = iter
        .next()
        .expect("Missing first number")
        .parse()
        .expect("Invalid integer for base");
    let shift: u32 = iter
        .next()
        .expect("Missing second number")
        .parse()
        .expect("Invalid integer for shift");

    // Compute the result: base OR (1 << shift)
    let result = base | (1_i64 << shift);

    // Output the result
    println!("{}", result);
}
