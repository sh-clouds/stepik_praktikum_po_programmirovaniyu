Остаток от деления на короткое

Напишите программу, вычисляющую остаток от деления двух целых неотрицательных чисел.

Входные данные

Дано одно число (длина которого не превышает 250 знаков) и число от 1 до 9999.

Выходные данные

Выведите остаток от деления первого числа на второе.

Sample Input:

7
3
Sample Output:

1
Напишите программу. Тестируется через stdin → stdout
Верно решили 111 учащихся
Из всех попыток 90% верных

# rust
use std::io::{self, BufRead};

fn main() {
    let stdin = io::stdin();
    let mut iterator = stdin.lock().lines();

    // Читаем первую строку (большое число)
    let dividend = match iterator.next() {
        Some(Ok(line)) => line.trim().to_string(),
        _ => return,
    };

    // Читаем вторую строку (делитель)
    let divisor_str = match iterator.next() {
        Some(Ok(line)) => line.trim().to_string(),
        _ => return,
    };
    
    let divisor: u64 = divisor_str.parse().expect("Некорректный делитель");

    // Вычисляем остаток
    let mut remainder: u64 = 0;

    for c in dividend.chars() {
        if let Some(digit) = c.to_digit(10) {
            // Формула: (текущий_остаток * 10 + новая_цифра) % делитель
            remainder = (remainder * 10 + digit as u64) % divisor;
        }
    }

    println!("{}", remainder);
}
