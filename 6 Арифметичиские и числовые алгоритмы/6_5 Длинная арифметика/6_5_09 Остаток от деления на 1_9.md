Остаток от деления на 1..9

Напишите программу, вычисляющую остаток от деления целого неотрицательного числа на натуральное однозначное число.

Входные данные
Дано одно число (длиной не более 250 знаков) и число от 1 до 9. Каждое число вводится на отдельной строке.

Выходные данные
Выведите остаток от деления первого числа на второе.

Sample Input:
7
3

Sample Output:
1

Напишите программу. Тестируется через stdin → stdout

# rust
use std::io;

fn main() {
    // Чтение первой строки (большое число)
    let mut big_num_str = String::new();
    io::stdin().read_line(&mut big_num_str).expect("Failed to read line");
    let big_num_str = big_num_str.trim();

    // Чтение второй строки (делитель)
    let mut divisor_str = String::new();
    io::stdin().read_line(&mut divisor_str).expect("Failed to read line");
    let divisor: u32 = divisor_str.trim().parse().expect("Invalid divisor");

    // Алгоритм нахождения остатка
    let mut remainder: u32 = 0;

    for digit_char in big_num_str.chars() {
        // Преобразуем символ в цифру
        if let Some(digit) = digit_char.to_digit(10) {
            // Формула: (предыдущий_остаток * 10 + текущая_цифра) % делитель
            remainder = (remainder * 10 + digit) % divisor;
        }
    }

    println!("{}", remainder);
}
