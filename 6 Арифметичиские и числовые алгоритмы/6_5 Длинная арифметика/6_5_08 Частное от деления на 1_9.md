Частное от деления на 1..9

Напишите программу, вычисляющую частное от деления числа N (целое, неотрицательное, не более 250 знаков) на натуральное однозначное число.

Входные данные
Дано одно число и число от 1 до 9, каждое число дано в отдельной строке.

Выходные данные
Выведите частное от деления первого числа на второе.

Sample Input:
9
8

Sample Output:
1

# rust
use std::io;

fn main() {
    let mut n_str = String::new();
    let mut d_str = String::new();

    // Читаем большое число N
    io::stdin().read_line(&mut n_str).unwrap();
    // Читаем делитель
    io::stdin().read_line(&mut d_str).unwrap();

    let n_str = n_str.trim();
    let divisor: u32 = d_str.trim().parse().unwrap();

    if n_str == "0" {
        println!("0");
        return;
    }

    let mut result = String::new();
    let mut remainder: u32 = 0;

    for c in n_str.chars() {
        let digit = c.to_digit(10).unwrap();
        let current = remainder * 10 + digit;
        
        let quotient = current / divisor;
        remainder = current % divisor;

        // Игнорируем ведущие нули
        if !(result.is_empty() && quotient == 0) {
            result.push_str(&quotient.to_string());
        }
    }

    // Если результат пустой (например, 2 / 5), выводим 0
    if result.is_empty() {
        println!("0");
    } else {
        println!("{}", result);
    }
}
