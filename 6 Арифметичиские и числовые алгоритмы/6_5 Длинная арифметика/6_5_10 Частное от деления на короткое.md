Частное от деления на короткое

Напишите программу, вычисляющую частное от деления двух целых неотрицательных чисел.

Входные данные
Дано одно число (длина которого не превышает 250 знаков) и число от 1 до 9999. Каждое число вводится на отдельной строке.

Выходные данные
Выведите частное от деления первого числа на второе.

Sample Input:
7
3

Sample Output:
2

Напишите программу. Тестируется через stdin → stdout
Верно решили 112 учащихся
Из всех попыток 92% верных

# rust
use std::io;

fn main() {
    let mut input1 = String::new();
    let mut input2 = String::new();

    // Считываем длинное число
    io::stdin().read_line(&mut input1).unwrap();
    let dividend_str = input1.trim();

    // Считываем короткий делитель
    io::stdin().read_line(&mut input2).unwrap();
    let divisor: u64 = input2.trim().parse().unwrap();

    let mut quotient = String::new();
    let mut remainder = 0u64;
    let mut leading_zeros = true;

    // Деление в столбик
    for c in dividend_str.chars() {
        let digit = c.to_digit(10).unwrap() as u64;
        let current_val = remainder * 10 + digit;
        
        let q_digit = current_val / divisor;
        remainder = current_val % divisor;

        if !(leading_zeros && q_digit == 0) {
            quotient.push_str(&q_digit.to_string());
            leading_zeros = false;
        }
    }

    // Если частное пустое (число делится нацело и равно 0)
    if quotient.is_empty() {
        println!("0");
    } else {
        println!("{}", quotient);
    }
}
